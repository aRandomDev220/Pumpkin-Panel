# Phase 4 (Config + Files) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Version-aware `pumpkin.toml` management (guided + raw, validated, revisioned, atomic) and a sandboxed per-server file manager with safe archive import/export.

**Architecture:** `toml_edit` preserves unknown keys and formatting (answers spec §30 Q9 — no reformatting surprises). Config saves are revision-checked transactions with pre-change copies in a new `config_revisions` table. File operations resolve inside the server root, reject escapes, and stream (never buffer whole files). Archives extract with entry allowlists + expansion caps.

**Tech Stack:** Rust Axum + `toml_edit 0.22`, `tar 0.4`, `flate2 1` (blocking archive I/O inside `spawn_blocking`); React 19 + TanStack Query frontend.

**Spec:** `pumpkin-manager-implementation-plan.md` (§13 Config, §14 Files, §17.3–17.4 API); trust boundaries §5.3/§12; error codes §9.4.

## Global Constraints

- Rust edition 2021; `cargo fmt --check` clean; `cargo clippy -p pumpkin-manager-backend --all-targets -- -D warnings` clean (documented `allow`s only).
- TypeScript strict; no `any`; `npm run build --prefix apps/web` clean.
- TDD: failing test first, watched fail, minimal code, full-suite green.
- Deps pre-added to workspace + backend crate (`toml_edit`, `tar`, `flate2`); stub modules + `mod` lines pre-wired in BASE — implementers NEVER edit `Cargo.toml`, `main.rs`, `migrations/` (except Task 2's 0003 file), or another task's files.
- SQL only via `sqlx` bind parameters, never string concat.
- Never log file contents, secrets, or full archives; audit config/file mutations without bodies.
- Commit ONLY the task's own files (`git add <exact paths>`); prefixes: `feat:` for code, `test:` only if tests-alone.
- No-subagents contract: implementers never dispatch subagents or reviewers.
- `main.rs` route wiring is the controller's job after all tasks land — handlers are standalone `pub async fn` taking `State<AppState>`.

## Review Focus

- Symlink inside the root pointing outside, then read through it — must be rejected, not followed (Task 3 owns: test).
- Tar with absolute + `../` + device + symlink-escape entries — all rejected before any write (Task 3 owns: test with crafted archive).
- Two concurrent PUTs with the same revision — exactly one wins, loser gets `409 CONFIG_CONFLICT` (Task 2 owns: test).
- 1 GiB upload must stream (bounded memory) — assert a 64 MiB upload succeeds and the route rejects over-limit with `413` (Task 4 owns: tests).
- Guided-form save must not drop unknown keys a raw edit added earlier (Task 1 owns: merge test).

### Task 3: Sandboxed file service + safe archives

**Files:**
- Modify: `crates/backend/src/file_service.rs` (stub exists)

**Interfaces:**
- Consumes: nothing from other tasks (pure filesystem service over a root dir).
- Produces (exact signatures for Task 4):
  - `pub struct Entry { pub name: String, pub entry_type: String, pub size: u64, pub mtime: String }` (`entry_type`: `"file"` | `"dir"` | `"symlink"`)
  - `pub enum FileError { NotFound, OutsideRoot, TooLarge, TooManyEntries, Io(String) }` + `pub fn code(&self) -> &'static str` (`PATH_OUTSIDE_SERVER_ROOT` for escapes, else `FILE_ERROR`/`NOT_FOUND`/`TOO_LARGE`)
  - `pub fn resolve(root: &Path, user_path: &str) -> Result<PathBuf, FileError>` (reject absolute + `..` lexically, then canonicalize-if-exists and re-check prefix; symlink parents that escape → `OutsideRoot`)
  - `pub async fn list_dir(root, path) -> Result<Vec<Entry>, FileError>`
  - `pub async fn read_file(root, path, max_bytes: u64) -> Result<Vec<u8>, FileError>`
  - `pub async fn write_file_atomic(root, path, data: &[u8], max_bytes: u64) -> Result<(), FileError>` (tempfile in same dir + rename)
  - `pub async fn create_dir(root, path)`, `pub async fn rename_path(root, from, to)` (both inside root), `pub async fn remove_path(root, path)` (file/dir recursive; refuse root itself)
  - Archive (all inside `spawn_blocking`): `pub fn export_tar_gz(root, rel_paths: &[&str]) -> Result<Vec<u8>, FileError>` (safe relative names only), `pub fn import_tar_gz(root, dest: &str, data: &[u8], limits: &ArchiveLimits) -> Result<usize, FileError>` (reject absolute/`..`/device/symlink-escape entries BEFORE any write; enforce caps) with `pub struct ArchiveLimits { pub max_files: usize, pub max_bytes: u64 }` and `pub const DEFAULT_ARCHIVE_LIMITS: ArchiveLimits = { max_files: 100_000, max_bytes: 10 * 1024 * 1024 * 1024 }`
  - `pub const MAX_FILE_BYTES: u64 = 64 * 1024 * 1024` (single-file read/write cap)
  - `pub const MAX_UPLOAD_BYTES: u64 = 1024 * 1024 * 1024` (route-level cap reference)
